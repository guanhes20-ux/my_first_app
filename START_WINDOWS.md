# Полная версия сайта на Windows

В архиве находятся фронтенд (templates, static), Python-бэкенд (app.py), Telegram-бот (bot.py), каталог автомобилей, тесты и инструкции.

1. Установите Python 3.12 или новее с python.org (поставьте галочку Add Python to PATH).
2. Распакуйте весь ZIP в отдельную папку, например D:\\Проекты\\Renta_Car. Не запускайте файлы из ZIP.
3. Дважды щёлкните start.bat. При первом запуске нужен интернет: программа создаст .venv и установит зависимости.
4. Откроется http://localhost:8000. Для админ-панели откройте http://localhost:8000/admin.
5. Пароль администратора находится в созданном файле .env, строка ADMIN_PASSWORD. Откройте его Блокнотом.

Оставляйте окно запуска открытым. Чтобы остановить сервер, нажмите Ctrl+C. Для повторного запуска используйте start.bat.

Существующий .env не перезаписывается. Если он содержит значения-заглушки, замените их по README перед запуском.
Не удаляйте и не публикуйте .env и папку data: там ключи и локальные данные. Архив GitHub содержит исходники, а не данные ранее запущенного сервера.

По умолчанию работает учебный режим. Используйте вымышленные сведения.

## Telegram-бот

Для полной цепочки бронирования через Telegram нужен работающий бот и доступный из интернета HTTPS-адрес Python-сервера. localhost и GitHub Pages для этого не подходят.

Укажите TELEGRAM_BOT_TOKEN и PUBLIC_URL в .env. Не отправляйте токен в чат и не загружайте .env на GitHub.
Оставьте сайт запущенным и откройте start-bot.bat во втором окне. Без настройки бота локально доступны сайт, каталог, расчёт и панель; анкету через Telegram получить нельзя.
Подробности запуска сервера и настройки HTTPS находятся в README.md.

## macOS / Linux

Запустите python3 scripts/start_local.py (Python 3.12+). Для бота: python3 scripts/start_local.py --bot.
