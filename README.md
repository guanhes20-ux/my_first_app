# Renta • прокат автомобилей в Калининграде

Учебный проект: Flask + SQLite + Telegram Bot API, интерфейс на HTML/CSS/JS, без сборки Node.
Каталог содержит **вымышленные автомобили, тарифы, госномера и VIN**. В режиме по умолчанию используйте только вымышленные персональные данные.

## Что реализовано

- Каталог 6 автомобилей с фильтрами по классу, адаптивный интерфейс, локальная SVG-иллюстрация (условная для всех моделей).
- Даты и время в Europe/Kaliningrad, UTC+2. Тариф за каждые начатые 24 часа, отдельный обеспечительный платёж.
- Серверная проверка периода, блокировка пересечений транзакцией SQLite, удержание на 30 минут.
- Переход в @Renta_Car_777_bot по непрозрачному идентификатору. Первая привязка к личному Telegram-аккаунту, анкета по временной ссылке.
- Бот направляет по шагам: /start, /status, /cancel, /delete. Он **не запрашивает паспорт и права сообщениями**: ввод происходит в анкете на сайте. Запускайте бот только с публичным HTTPS-адресом.
- ФИО, телефон, паспортные реквизиты, адрес, водительское удостоверение, даты и стаж. Категорию B, подлинность и действительность документов проверяет менеджер.
- Раздельные согласия, версия текста и время согласия, шифрование полей анкеты Fernet; ключ хранится отдельно от базы.
- Панель /admin: просмотр, проверка, подтверждение, отмена, удаление; DOCX с двумя экземплярами договора, Excel с заявками и статистикой.
- Закрытые выгрузки с паролем и сессией, CSRF, ограничение частоты запросов в одном процессе, защита Excel от формул.
- GitHub Actions: проверка синтаксиса Python/JS и функциональные тесты.

## Быстрый запуск (Python 3.12)

GitHub хранит исходники. GitHub Pages не запускает Python, бота или SQLite.
Сайт и бот запускаются **двумя процессами на одном компьютере/сервере с общей папкой data**.

```bash
git clone https://github.com/guanhes20-ux/my_first_app.git
cd my_first_app
git switch feat/renta-car
python -m venv .venv
# Linux / macOS
source .venv/bin/activate
# Windows PowerShell вместо предыдущей строки:
# .venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Скопируйте .env.example в .env и задайте значения. Приложение использует переменные окружения; файл .env загружается Flask CLI при наличии python-dotenv. Для одинакового запуска сайта и бота установите загрузчик:

```bash
pip install python-dotenv==1.2.1
python -c "import secrets; print(secrets.token_urlsafe(48))"
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

Первый результат — APP_SECRET, второй — DATA_KEY. ADMIN_PASSWORD — отдельный пароль от 16 символов.
**Не теряйте DATA_KEY**: без него нельзя прочитать анкеты. Не коммитьте .env, базу, отчёты, договоры и резервные копии.

Запуск сайта с загрузкой .env:

```bash
python -m dotenv run -- python app.py
```

Откройте http://localhost:8000, панель http://localhost:8000/admin.
Для проверки бота нужен доступный из интернета адрес сайта с HTTPS: задайте PUBLIC_URL, затем:

```bash
python -m dotenv run -- python bot.py
```

**Токен, ранее отправленный в переписку, необходимо отозвать через BotFather (/revoke).**
Новый токен задайте только в TELEGRAM_BOT_TOKEN в локальном .env / секретах сервера.
Он отсутствует в коде и истории проекта. Имя бота уже задано: Renta_Car_777_bot.
Один токен должен обслуживаться одним процессом long polling, без активного webhook.
Если ранее был webhook — удалите его через Bot API без публикации токена в логах.

## Рабочий сценарий

1. Выберите авто → даты/время → «Продолжить в Telegram» → «Открыть Telegram» → Start.
2. Бот выдаст ссылку на анкету сроком до 20 минут, в пределах 30-минутного удержания.
3. Заполните вымышленные сведения и отдельные согласия. Повторная отправка ссылки закрывается.
4. Менеджер входит в /admin, раскрывает документы, проверяет и подтверждает.
5. Скачивает DOCX «2 экземпляра» и Excel на свой компьютер. Файлы генерируются при запросе и не сохраняются в репозиторий.
6. Для подписания распечатайте DOCX, заполните незаполненные условия и подпишите оба экземпляра с актами.
7. Бот показывает статус по /status. Автоматические уведомления о подтверждении и платежи в проект не включены.

Заявка сама по себе не является подписанным договором. Сумма подтверждённых заявок в отчёте — не бухгалтерская выручка и не доказательство оплаты.
Удаление в панели необратимо; используйте его с учётом обязанностей хранения подписанных договоров.
Команда /delete удаляет неподтверждённые заявки только текущего Telegram-пользователя.
Команда /cancel отменяет его удержания и анкеты на проверке; подтверждённый договор отменяет менеджер по согласованию.

## Развёртывание

Для учебной демонстрации — локальный компьютер с HTTPS-доменом/сервером, без реальных документов.
Для работы с реальными данными сначала завершите юридическую и техническую подготовку (см. docs/LEGAL.md).

На Linux-сервере в РФ:
- Python 3.12 и зависимости, выделенный системный пользователь.
- Nginx/Caddy с TLS → Gunicorn; файлы базы и ключ шифрования в защищённом каталоге, резервные копии зашифрованы.
- PUBLIC_URL=https://ваш-домен; переменные окружения передаются средствами systemd/секретов сервера.
- Сайт: `gunicorn --workers 1 --threads 4 --bind 127.0.0.1:8000 'app:create_app()'`.
- Бот: `python bot.py`, один экземпляр. Переменные должны быть заданы для обоих процессов.
- Не запускайте dev-сервер app.py в интернете, не включайте Flask debug.
- Лимит запросов в учебной версии локален одному web-процессу. Для масштабирования нужны Redis-лимиты, PostgreSQL, доверенные настройки reverse proxy и аудит.
- Не публикуйте папку data через web-сервер. Не включайте URL анкет с токенами в access-логи. Nginx: отключите access_log для /application/; запретите логирование request body и окружения.
- TELEGRAM_BOT_TOKEN не должен попадать в журналы HTTP-клиента.
- Для удаления старых истёкших/отменённых заявок запускайте ежедневно из того же окружения: `flask --app app:create_app purge-expired`. RETENTION_DAYS=30 по умолчанию. Заявки submitted/confirmed обслуживаются отдельно по утверждённому регламенту.
- Доступ к api.telegram.org должен быть разрешён хостингом. В текущем облачном окружении этот адрес не настроен; бот здесь не запущен.

DEMO_MODE=false требует HTTPS, LEGAL_REVIEWED=true, OPERATOR_NAME и OPERATOR_DETAILS.
Эти флаги — организационный барьер, **не сертификат соответствия законодательству**.
Перед боевым запуском замените все автомобили, цены, VIN/номера и заполните шаблон договора.
Электронная подпись, онлайн-оплата, касса, проверка подлинности документов по реестрам и автоматическая печать не реализованы.

## Проверки

```bash
python -m pytest -q
node --check static/app.js
```

Тесты проверяют стоимость, пересечение дат, истечение удержаний, CSRF, недоступность приватных выгрузок, привязку Telegram, отдельное согласие, шифрование, DOCX с двумя экземплярами, XLSX и удаление с разграничением доступа.
Облачный исполнитель при создании проекта не запустился: локальные тесты, браузер и реальная связь с Telegram не были проверены. См. результат GitHub Actions после загрузки.

## Структура

- app.py — сервер, бронирование, анкета, панель, документы.
- bot.py — Telegram long polling; без токена в исходниках.
- templates/, static/ — интерфейс.
- cars.json — учебный каталог.
- tests/ — проверки.
- docs/LEGAL.md — юридическая подготовка и ограничения шаблона.
